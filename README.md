# 图像混淆 · 反混淆工具

一个完全在浏览器本地运行的图片置乱与无损还原工具。上传任意图片，选择一种混淆算法生成「混淆图」，再用相同的密钥一键反混淆还原，并自动进行像素级一致性校验。

## 功能特性

- 三种混淆算法：Arnold 猫脸变换 / 像素随机置乱 / 分块置乱（拼图式）
- 无损还原：还原结果与原图逐像素一致（差异为 0）
- 密钥机制：迭代次数 / 随机种子 / 块大小即密钥，还原必须使用相同密钥
- 本地处理：所有计算在浏览器内完成，图片不会上传到任何服务器
- 支持拖拽上传与示例图，原图 / 混淆图 / 还原图三联对比，可下载 PNG

## 使用方法

1. 用浏览器打开 `图像混淆与反混淆工具.html`（无需联网、无需安装）
2. 点击或拖拽图片到上传区域，也可直接使用「示例图」
3. 选择算法并设置密钥参数，点击「生成混淆图」
4. 点击「反混淆还原」，查看还原结果与像素一致性校验

## 算法说明

| 算法 | 原理 | 密钥 |
| --- | --- | --- |
| Arnold 猫脸变换 | 像素坐标经 (x, y) → (x+y, x+2y) mod S 迭代置乱 | 迭代次数 N |
| 像素随机置乱 | 按种子对全部像素做 Fisher-Yates 均匀置换 | 随机种子 |
| 分块置乱 | 将图像切成小方块后按种子打乱顺序 | 随机种子 + 块大小 |

三种算法均为整像素可逆变换，不经过有损压缩；非方形图片会自动补透明边，还原后裁回原尺寸。

## 技术实现

- 纯原生 HTML / CSS / JavaScript，单文件自包含，无任何外部依赖
- 像素级变换基于 Canvas `ImageData`，使用 `Uint8ClampedArray` 内存操作
- 确定性伪随机数生成器（mulberry32）+ 字符串哈希（cyrb53 风格）生成置换序列
